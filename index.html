How to Use

使用方式

同一套页面，三种用法：课堂边讲边跑、学生按清单自学、教师改 demo 复用。

课堂讲解

打开任一章节后，左侧选小节，顶部切换 讲解 / 代码 / 演示 三个 tab，一边讲原理、一边实时运行。

学生自学

按章节顺序过完所有 关键点，每个关键点配有「为什么这么写」+「有什么坑」；配合本页学习清单自我检验。

教师备课

每个章节有独立的 demo/ 子目录与完整讲义 lecture.md，可单独跑、单独改、单独打包给学生。

局域网使用

若公网不通，可在本机运行 python -m http.server 8080，学生连同一 WiFi 即可访问，无需安装任何依赖。

About

关于本课程

案例为中心，理论嵌进代码里；全程零视频、零构建，一个静态目录即可部署。

理论来源

陈为《可视化导论》、Mackinlay 1986、Stevens 1946、Cleveland 1984、Card 1999 数据流模型、van Wijk 2005、Bostock D3 官方文档。

设计原则

案例为中心（不是理论为中心）。每个知识点都嵌入实践案例，配关键点解释 + 可运行演示，让抽象概念当场可见。

技术栈

零依赖：纯 HTML + CSS + JavaScript + D3.js v7（CDN）。本地一条命令 python -m http.server 启动，无需 npm 与构建步骤。

数据集

新生数据 CSV 与 Crime 数据等已打包进 data/ 目录，浏览器 fetch 加载，离线可用；全部为文本与脚本，占用空间极小。
